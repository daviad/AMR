> 目的：用改完的 URDF（前脚轮 `mu=0.02`、`base_footprint`、spawn `z=0.01`）重新建一张室内地图，
> 覆盖全部区域，然后用新图跑完整导航栈 3 个航点，验证建图与导航是否正常。

## 2. 建图流程

### 2.1 停旧栈 → 建图模式

```bash
cd /home/dxw/amr && ./amr_start.sh --stop
env -u LD_LIBRARY_PATH bash docs/amr_probe_scripts/start_mapping.sh   # 等价于 ros2 launch amr_slam mapping.launch.py
```

- Cartographer 配置：`tracking_frame=imu_link`、`published_frame=odom`、`provide_odom_frame=false`（不引用 base frame，不受 URDF 改动影响）。
- 就绪判据：`/scan` ≈10 Hz、`/odom` 50 Hz、`/map` 有数据、日志出现 submap 插入（`check_map.sh`）。

### 2.2 全覆盖路线

- 区域划分：下部横带（y∈[-3.9,-0.1]）+ 上部西区（x∈[-4.9,0.9], y∈[0.1,3.9]）+ 上部东区（x∈[1.1,4.9], y∈[0.1,3.9]），
  用蛇形扫描逐区覆盖，入口分别走 `x≈-1.4/y≈0.3`（绕过 `partition_h1`）与 `x≈1.4/y≈0.2`（绕过 `partition_v1` 南端缺口）。
- 驾驶：`coverage_route.py` 以 `/gz_truth` 真值闭环（真值只用于脚本驾驶，不参与建图），
  直行 0.22–0.30 m/s，航向偏差 >0.55 rad 先原地对齐；到点判据 0.12 m，单点超时 90 s，总超时 900 s。
- 结果：**34/34 航点全部到达，总耗时 273.4 s，终点 (0.075, 0.081) yaw −149.9°**。

```bash
env -u LD_LIBRARY_PATH bash docs/amr_probe_scripts/run_coverage.sh
# 原始日志：/tmp/amr_probe/coverage.log；结果：/tmp/amr_probe/coverage_route.json
```

### 2.3 保存地图

```bash
env -u LD_LIBRARY_PATH bash docs/amr_probe_scripts/save_map.sh   # ros2 run amr_slam save_map indoor 15.0
```

- 保存位置：`amr_sim_ws/src/amr_nav/maps/indoor.{yaml,pgm}`（`install/` 为 symlink，导航栈直接生效）。
- 旧图备份（**未删除**）：`maps_backup/20261108-old-indoor/`（在 `maps/` 之外），含 `indoor.pgm`、`indoor.yaml`。
- 新图：**214×175 @0.05 m，跨度 10.7×8.75 m，origin (−5.222, −4.4)**。
